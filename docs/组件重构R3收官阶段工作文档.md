## 三、关键实现决策

1. **CheckBox 用 Click 而非 Checked/Unchecked（防重入）**。XAML 中 `IsChecked="{x:Bind Done}"` 在模板实例化时赋值会触发 Checked/Unchecked；若订阅这两个事件，"赋值 → 事件 → 落盘 → 重载集合 → 新模板实例再赋值"会形成刷新循环。旧 code-behind 靠"先赋值、后挂事件"的顺序规避，XAML 化后不可行。`Click` 只由用户交互 / 自动化触发（程序化赋值不引发），语义等价且无重入；处理函数读点击后的 `IsChecked` 即为目标状态（ToggleButton 先翻转后触发 Click）。
2. **增量更新语义**。勾选 / 保存 / 删除后只重载列表集合（Clear+Add，沿用 QuickLaunch 模板的既定模式）；因 `WidgetStorage.Normalize` 在 Save 时重排序（未完成在前、组内时间倒序），整列表重载是保持既有排序语义的最小正确实现。由此带来两处行为改进（R3 目标内）：输入框内容不再被整树重建清空；滚动位置不再整树跳变。
3. **Toggle 增加 no-op 守卫**。`Done` 未变化时不落盘不刷新，防御未来事件接线变化引入的无谓 IO，不改变可观察行为。
4. **Clock 启停接线**。宿主继续持有可见性状态（Reveal / HideTemporary / AppWindow.Changed / Shutdown / Closed 职责不变），组件暴露 `UpdateRunning(AppWindow.IsVisible)` 与 `Stop()`；启动即先校准一次显示；`Unloaded` 兜底停表；重复订阅用 `-=`/`+=` 防护（沿用旧 UpdateClockTimer 写法）。字段 `_clockWidget` 由 `BuildContent()` 以 `content as ClockWidget` 捕获，非 Clock 窗口恒为 null，等价旧的 kind 分支判断。
5. **视觉一致性**。完成态 0.45 透明度 + Strikethrough 通过两个小转换器实现（沿用 SearchWidget 的 TagSelectedBrushConverter 模式，声明在 UserControl.Resources）；行布局、边距、字号、占位文案与原 code-behind 逐项对齐；QuickNote 卡片沿用 `WidgetSubtleFillBrush` 主题资源。

## 六、环境与工程备注（坑位沉淀）

1. 构建命令必须带 `--disable-build-servers`（规避偶发 MSB3027 DLL 锁定）。
2. 本会话环境 `DOTNET_ROOT` 预设指向仅含 .NET 8 运行时的 AutoClaw 目录（`D:\AutoClaw\resources\dotnet\win-x64`），`dotnet test` 的测试宿主会因缺 9.0 运行时启动失败；须改指 `C:\Program Files\dotnet`（SDK 9.0.310）并前插 PATH。直接 `dotnet` 命令亦被同名遮蔽，建议全程用完整路径调用。
3. 仓库工作树为 UTF-8（无 BOM）+ LF；git `core.autocrlf=true` 提交时归一化，diff 干净；新文件按同约定写入。
4. 提交信息含中文时经 PowerShell `-m` 传参可正确存储为 UTF-8（`git log` 直出验证）；经管道读取 git 输出时注意 `[Console]::OutputEncoding`，否则中文显示为乱码假象。
5. UI/XAML 改动后必须显式 `dotnet build StarMark.sln`：StarMark.Tests 不引用 StarMark.UI，测试全绿不代表 UI 程序集可编译（本阶段每步均显式构建验证）。

## 七、补记（2026-09-17）：搜索/置顶缺陷修复

用户实测反馈三个缺陷，根因定位与修复如下（构建 0 错 0 警、测试 169/169 复验通过）：

| 缺陷 | 根因 | 修复 |
|---|---|---|
| 搜索组件标签全被遮挡（标签多时不可达） | 标签行是 36px 高的横向单行滚动（ItemsRepeater + StackLayout），标签一多整行被裁剪，且鼠标滚轮无法横向滚动 | 自写 WrapPanel（WinUI 3 无内置 WrapLayout，ItemsRepeater 不接受非虚拟化布局）配合 ItemsControl 换行铺开，MaxHeight 132 内垂直滚动，全部标签可达 |
| 无法搜索本地文件 | 组件直查 IItemRepository（纯 FTS5），绕过主窗口同源的 SearchService（FTS5 + Everything 实时源合并去重），未入库的本地文件永远搜不到 | 构造时从 DI 解析 SearchService 走统一编排（空关键词 + 标签退化为按标签浏览的规则与主窗口一致）；拿不到服务时回退仓库直查。附带修复：SearchBox 的 KeyDown 此前未在 XAML 接线，回车搜索不触发，只有按钮可用 |
| 条目置顶后无法取消置顶 | ItemCardViewModel 构造只映射 IsHidden 未映射 item.Pinned：置顶条目在主窗口永远显示为未置顶，点「置顶」只会再次写入 pinned=1 | 构造补映射 IsPinned = item.Pinned，PinMenuText 正确切换「取消置顶」并可正常切换状态 |

复核提示：GUI 交互仍需人工冒烟（标签换行可达性、本地文件搜索命中、置顶切换）。
