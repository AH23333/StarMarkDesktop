# StarMark v1.0.0

第一个公开版。装好之后不需要账号、不需要联网也能用大部分功能：数据全在本机 SQLite 里。

**运行前请先装 [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0)**（这一版是框架依赖分发，没带 .NET 运行时；Windows App SDK 的运行时在包里，不用另装）。解压 `StarMark-1.0.0-win-x64.zip` 到任意目录，运行 `StarMark.UI.exe`。

## 这一版能做什么

- **跨源统一搜索**：GitHub Stars、Chrome/Edge 书签、本机文件（全盘、按文件名）、内置剪贴板历史、待办与随记，一个框里一起搜；FTS5 全文索引 + 相关度排序，中文按字切分。
- **标签与笔记**：任何来源的条目都能打标签、写笔记、置顶、隐藏，标签和笔记本身也进搜索。
- **桌面组件 17 种**：快捷启动、时钟（含闹钟）、待办、随记、快捷搜索、标签、剪贴板、最近活动、置顶条目、今日速览、天气、音乐、计算器、世界时钟、倒计时、番茄钟、系统监控。可拖动、边缘吸附、缩放、置顶、重命名，布局可保存多套。
- **截图 / 贴图 / 屏幕画布**：Snipaste 式的截图标注（形状、画笔、荧光笔、马赛克、文字、折线、序号），贴图可就地继续编辑并成组管理；屏幕画布默认穿透、按住即画，带白板底与幕布。文字识别走系统引擎。
- **GitHub 热榜 / RSS**：热榜页可以直接 Star 或取消 Star；RSS 支持文件夹与收藏入库。
- **剪贴板历史**：默认关闭，文本与图片都记（图片按上限落盘并轮转），三层敏感内容拦截。
- **AI 批量整理标签**：接本机 Ollama 或任意 OpenAI 兼容端点，先出分组预览再一次性写入，可以中途停止。
- **备份与快照**：手动导出/导入、自动备份（间隔可设）、组件布局与数据的快照。
- **自动更新**：设置页「关于与更新」里能看到有没有新版；点「立即更新」会下载并校验后替换，替换失败自动退回原版本。

## 已知边界

- 本地文件搜索**只按文件名**检索，不搜文件内容。
- 需要 Everything 的全盘索引：第一次打开「本地磁盘搜索」开关时会自动准备（随包副本优先，没有副本时从官网下载官方 standard 便携版到本程序自有目录），需要联网一次。
- 本程序不做自我提权。以管理员身份运行本程序、而资源管理器或浏览器是普通权限时，跨权限的拖放会被系统拦下——这是 Windows 的规则，不是这里的缺陷，界面上会把当前权限状态说出来。
