# StarMark v1.0.5

这一版的主角是**运行时换轨**：整个程序从 .NET 9 迁到 .NET 10，界面与功能一切照旧，但底下的运行时要求变了（见下面那段加粗）。另外两件：**AI 批量整理的韧性**——服务商断联、限流、额度耗尽各有各的对策，不再一律干等满超时；**界面语言切换的重贴兜底**——换语言那一下不再有元素停在旧语言。自 v1.0.4 以来这一版积了 422 个提交，下面按用户看得见的挑大件说。

**运行前请先装 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)**。解压 `StarMark-1.0.5-win-x64.zip` 到任意目录，运行 `StarMark.UI.exe`；或者用 `StarMark-1.0.5-setup.exe` 安装。

## 怎么升上来

打开 StarMark → 设置 → 「关于与更新」→ 看到「有新版本 v1.0.5」后点「立即更新」。程序下载载荷、核对清单签名与逐文件 SHA-256，再由独立更新器替换文件。

⚠ **从 v1.0.4 升上来，请先把 .NET 10 Desktop Runtime 装上，再点「立即更新」。** v1.0.4 跑在 .NET 9 上，而这一版要 .NET 10；更新器替换文件时不会替你检查运行时，如果机器上还没有 .NET 10，更新完程序起不来，会弹窗让你装运行时——**装上就能起，不用重新更新**，但先把运行时装好可以省这一下。用安装包或 zip 手动升的人同理。

## 这一版具体改的几件

1. **AI 批量整理的韧性四臂。** 批内失败重试带退避（服务商断联或限流时先等一小会儿再试，不再每批干等满超时）；连续失败到阈值**熔断**，剩余批次不再白烧（点一次还能继续从断点跑）；**「额度耗尽」与「限流」分开说**——前者直说去充值或换通道，不再假装是网络问题；批量整理出问题时设置页顶部有**显著警示横幅**，不再只有日志里一行小字。行为有测试钉住。
2. **AI 仪表盘。** 设置页「AI 增强」多了一块仪表盘：全期用量汇总、近 14 天按日趋势、最近 10 条明细。想看这个功能烧了多少，一眼有数。
3. **撤销上一次 AI 整理。** 整批撤销（差集留档），误整理不用一条条手动改回来。
4. **AI 分类省 token。** 批里同款条目只问模型一遍，答案扇出到同类各条——同样的批量，问的次数更少。
5. **界面语言切换重贴兜底。** 换语言那一下逐颗元素重贴，某一颗断线不再让整批停在旧语言；日历与组件的屏幕文字也跟着换干净。
6. **贴图跨会话持久化。** 每张贴图落成 PNG 加元数据，重启程序不再消失。
7. **剪贴板历史选择器浮层。** 默认 Ctrl+Alt+V 呼出，对标 Win+V 的体验；剪贴板也进了主窗口的第 5 档来源。
8. **画布与截图链打磨。** 截图工具新增显式「选择」工具（点选、框选、组拖、组删）；深浅色真因修复——深色用户再不会发现画板被顶回浅色；同一块画布连点两下不再二次冷启；关开关会逐窗协商收窗。

## 还有一批修复

- **卡顿**：打开设置页（导航缓存）、展开更多（增量分帧）、磁盘事实全部挪出 UI 线程、日志后台写盘——这几处点开要等一下的都收掉了。
- **崩溃止血**：后台强推 GC 与 XAML 线程竞态的访问违规修掉了（真机首崩定位后修复）。
- **圆角拖到最小**不再跳回系统默认；**拖放有回执**，三个去处当面说清。
- **失联书签对账**：浏览器里删掉的书签行灰显，设置页一键清。
- **GitHub Star 收藏时间用真 starred_at**，「最近 Star」排序如如其名。
- **密钥落盘加密**：GitHub Token 与 AI Key 走 Windows DPAPI，不再是明文。
- 搜索增量同步（击键去抖后不再整表重建）、备份全链可取消、音乐组件与书签同步的日志降噪、若干提示句说得出原因。

## 已知边界（说清楚，免得被当成坏了）

- **.NET 10 运行时是硬要求**（见上面那段 ⚠）。v1.0.3 及更早升上来的机器同样适用：先装运行时再更新。
- AI 韧性的重试与熔断行为有测试钉住，但**限流档位的真实触发**依赖服务商真的限流，真机上还没等到过——遇到时按横幅与提示走即可。
- AI 相关 API 实测在部分通道上尚未全量跑过，遇到问题看设置页横幅与日志。
- 热键若被其它程序占用（如个别机器上的 Ctrl+Alt+P），注册失败会留一行日志，其余热键不受影响。
- 更新只走 GitHub 上这一个仓库，载荷要过签名与逐文件哈希两关；任一处对不上就不装，本机一个字节都不改。
- 本地文件搜索只按**文件名**找，不搜文件内容（这是产品边界，不是缺陷）。
