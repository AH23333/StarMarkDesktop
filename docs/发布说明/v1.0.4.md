# StarMark v1.0.4

这一版的主角是**界面语言**：简体中文／English／日本語 三语的屏幕文字收进了一份语言表，切换之后**当下这一屏就跟着换**，不用重启程序。另外三件：**第一次公开安装包**、首启引导与每页的「？」、应用图标重画。

**运行前请先装 [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0)**。解压 `StarMark-1.0.4-win-x64.zip` 到任意目录，运行 `StarMark.UI.exe`；或者用 `StarMark-1.0.4-setup.exe` 安装（见第三件）。

## 怎么升上来

打开 StarMark → 设置 → 「关于与更新」→ 看到「有新版本 v1.0.4」后点「立即更新」。程序下载载荷、核对清单签名与逐文件 SHA-256，再由独立更新器替换文件。

**从 v1.0.3 升上来的这一跳，替换失败会把你原来那一版重新起来。** 保护它的更新器来自你当前装着的那一版，而 v1.0.3 已经带着修好的那颗——所以这一跳不用再走旧行为。（更早那两版升上来的中间跳仍是旧样子：程序停下、本机一个字节不改、日志写明原因，但不会自己把窗口开回来。）

## 这一版具体改的四件

1. **界面语言全量化，而且当场生效。** 入口在设置 → 「常规」→ 界面语言。主窗口的每一页、设置页的八栏、桌面组件的窗口与右键菜单、托盘菜单、截图／贴图／画布的那两条工具条与提示卡、提示卡与窗口标题，以及快捷键那一栏的动作名与分类名，都从语言表出话。日期、星期、数字与"多久之前"这类读数也跟着语言走；今日速览那一行的节日倒计时按语言各排一张表（中文走农历、英文走美国节日、日文走日本年中行事）。
2. **首启引导与就地求助。** 第一次启动会给你一段一次性引导，讲清主窗口、组件、全局热键这三样怎么用；此后每一页右上角都有一颗「？」，点开就是**这一页**的说明，不用去翻文档。设置页另有「使用说明」一整栏。
3. **第一次公开安装包 `StarMark-1.0.4-setup.exe`。** 它会登记卸载入口、建开始菜单项、可选放桌面图标。默认落点是**「只给我装」**（装进你自己的用户目录）——这不是保守：自更新要往安装目录里写文件，装在受保护位置时非提升的更新器写不进去，那一版就再也更新不动了；想「给这台机器所有人」在安装时当场选，程序会把代价说明白。⚠ 如果这台机器以前装过「为所有用户」的那一份，新包会沿用原来那条路径升级（这是安装框架继承来的行为），所以「只给我装」这个默认**只对没有旧安装的机器生效**。
4. **应用图标重画**（标题栏、任务栏、托盘、安装包读的都是同一份文件）。旧的四角星形状换掉了，但**组件的名字与位置不受影响**：这一版没动任何标识用的键。

## 还有一批"屏幕上说不清"的修复

- 设置页两处摆位：「主题」「界面语言」两张卡的名字现在与它们各自的控件**同一行**；「AI 增强」那一栏里一句没有正文的标题不再压住「Ollama 地址」。
- 「AI 增强」那两句长说明不再把卡片撑出一条横向滚动条；说明里提到的东西都在同一页能点到。
- 加载失败、剪贴板内容已不在本机、贴图组超出上限、备份删除确认这些提示**说得出原因**，也不再只给一句"请重试"。
- 「未设置」与"有几个冲突"这类热键读数、健康那一栏那几行、以及若干组合句，改成**按键现取**：换语言那一刻不需要重进那一页。
- 若干只进日志、永不上屏的句子被删掉或改中性，不再冒充界面文字。

## 已知边界（说清楚，免得被当成坏了）

- 「只给我装」这个新默认⛔ 对你机器上**已有**的安装生效（见第三件那条 ⚠）。要把已装的那份挪到用户目录，目前的办法是先卸载再装一次；这个动作我们仍然⛔ 在你这台机器上点过，所以它的照片还欠着。
- 安装包的**编译与产物自证**过了；「装上／卸载／缺运行时那道提示」这三格只有真机能点，我们还没补到照片。zip 解压版是这一条链上最早被真启动验过的那条路径，用它兜底不会更差。
- 布局这一版逐档量过的是 900／918／960／1440 四颗窗宽 × 设置页八栏 × 三语；**别的 DPI／缩放档位仍没量过**。如果你把窗口拉得很窄或系统缩放不是 100%，看到某一行挤在一起，那属于没量到的那一档，不是新坏掉的。
- 清单新鲜度：从这一版起，更新清单里带"这份清单签于何时"，设置页会告诉你它是几天前签的。`v1.0.3` 及更早那三份清单没有这一欄，程序读到它们时那一格显示"不知道"——**不判、不拦、不念**，所以停在旧版还没升上来的机器不会因为这一欄被挡。
- 更新只走 GitHub 上这一个仓库，载荷要过签名与逐文件哈希两关；任一处对不上就不装，本机一个字节都不改。
- 本地文件搜索只按**文件名**找，不搜文件内容（这是产品边界，不是缺陷）。
