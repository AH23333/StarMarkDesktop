# StarMark v1.0.6

这一版是个小版本，两件主角：**应用图标换新为「星群」**——收进 StarMark 的每条东西都是一颗星，应用把它们连成星群，一颗孤星换成主星带双星芒、连线与星点的一群星；**本地磁盘搜索的进程泄漏修复**——关掉「本地磁盘搜索」开关或退出程序时，为它拉起的那只自带 Everything 后台进程现在会被一并收走，不再白留在后台吃整套全盘索引的内存。自 v1.0.5 以来这一版积了 6 个提交，用户看得见的就是这两件。

**运行前请先装 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)**（v1.0.5 起的硬要求）。解压 `StarMark-1.0.6-win-x64.zip` 到任意目录，运行 `StarMark.UI.exe`；或者用 `StarMark-1.0.6-setup.exe` 安装。

## 怎么升上来

打开 StarMark → 设置 → 「关于与更新」→ 看到「有新版本 v1.0.6」后点「立即更新」。程序下载载荷、核对清单签名与逐文件 SHA-256，再由独立更新器替换文件。

从 v1.0.5 升上来**不换运行时**，直接点「立即更新」即可。v1.0.4 及更早的机器：先把 .NET 10 Desktop Runtime 装上再点「立即更新」（v1.0.5 说明里那段 ⚠ 原样适用——装上就能起，不用重新更新）。

## 这一版具体改的几件

1. **应用图标重绘：「星群」。** 一颗孤星换一群星——主星（五角尖朝上、品牌金）带双星芒、连线与星点；16px 这类小尺寸自动简化成主星加一颗星芒，保住清晰。任务栏、窗口标题栏、系统托盘、安装包同一套语言。
2. **关掉本地磁盘搜索/退出时收走自带的 Everything。** 此前为搜索拉起的那只隐藏 Everything 进程，在开关关掉或程序退出后会留在后台白吃内存；现在这两处都会一并收走。只收 StarMark 自己下载的那只——用户自装的 Everything 一概不碰；重开开关由就绪流程重新拉起，索引库在盘上，重启很快。

## 已知边界（说清楚，免得被当成坏了）

- **.NET 10 运行时是硬要求**（见上面那段加粗）。v1.0.3 及更早升上来的机器：先装运行时再更新。
- 本地文件搜索只按**文件名**找，不搜文件内容（这是产品边界，不是缺陷）。
- 热键若被其它程序占用（如个别机器上的 Ctrl+Alt+P），注册失败会留一行日志，其余热键不受影响。
- 更新只走 GitHub 上这一个仓库，载荷要过签名与逐文件哈希两关；任一处对不上就不装，本机一个字节都不改。
