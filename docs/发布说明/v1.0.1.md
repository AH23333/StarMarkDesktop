# StarMark v1.0.1

与 v1.0.0 的程序能力相同，这一版的意义在于**更新链路**：它是第一个由 v1.0.0 点「立即更新」真装成功的版本，所以这一条链第一次有了"两版之间"可走。功能说明见 v1.0.0 那一条。

**运行前请先装 [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0)**。解压 `StarMark-1.0.1-win-x64.zip` 到任意目录，运行 `StarMark.UI.exe`。

## 已经装了 v1.0.0 的人怎么升

1. 打开 StarMark → 设置 → 「关于与更新」；
2. 看到「发现新版本 v1.0.1」后点「立即更新」；
3. 程序会下载载荷、校验清单签名与逐文件 SHA-256，再由独立更新器进程替换文件；
4. 任一步失败都会自动退回原来的那一版，并在界面上说清是哪一步没成——不会留下一个打不开的半棵树。

## 这一版顺带证明的事

- 发布产物里必须同时有主程序与 `Updater\` 整目录，少带更新器 ⇒ 用户点「立即更新」只会得到"没能起来"，而且那一版之后再也更新不了；
- 换载荷必须三颗（zip + 清单 + 签名）一起换：只换 zip 留下的是"新包配旧清单"，用户那一侧表现为审包永远拒收，而界面上一直显示"有更新"却装不上；
- 对账要比 sha256，不能只比字节数：重新签一次名出来的串和原来一样长。
