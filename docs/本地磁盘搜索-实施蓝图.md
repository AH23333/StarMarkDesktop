## 1. 需求与硬约束（勿推翻）
- 目标：像 Everything 一样**全盘、秒出**搜本地文件名。承载组件 = **快捷搜索 / 主窗搜索栏**（**不是**搜索结果格）。
- 已排除路线：A 托管按根目录扫描（配置差异致体验分裂）、B Windows 索引 `Search.CollatorDSO`（受制用户系统设置）、C 读 `Everything.db`（版本锁死）。
- 硬三角：**免管理员 / 不依赖用户配置 / 全盘秒出** 三选二。要"全盘+秒出+不依赖配置"必须直读 `$MFT`+USN ⇒ 必须提权。

## 2. 选定架构（方案 A）
- 一个以 **SYSTEM 常驻的提权后台服务**持有全盘索引，经**命名管道 IPC** 应答查询；**StarMark 主程序保持普通权限**（不整程序 runas）。
- **服务内核复用 Everything**：服务内部托管一个私有 Everything 实例作为索引引擎，对用户完全不可见（工程量减半、最稳）。用户视角"开功能→授权→等待首扫→可搜"，无 Everything 心智负担。
- **开关式生命周期（内存优先）**：默认**关**。关时不装/不启服务、不加载索引 → **额外内存 0**；开启才懒起；关闭即停回落。
- 交互门：`Disabled / NeedsSetup / Starting / Indexing / Ready`。**未授权（NeedsSetup）绝不提示"扫描进行中"**，只有越过授权、真在建立索引（Indexing）才提示等待。

## 3. 已落地（AB，可机检，真机待验）

## 4. 待落地批次（均需真机 `[v]`，本沙箱不可运行服务/MFT/管道/Everything）
- **AC-D1 服务宿主与安装**：新建 `StarMark.FileIndexService`（.NET Worker / Windows Service，`sc create` 或 `scutil` 自安装），服务内以受限目录启动 Everything 私有实例（`-nonewipcserver` 关闭其对外 IPC，仅本服务经内部管道对话）。开机不自动跑，仅在开关开启时安装并 `sc start`。
- **AC-D2 IPC 契约**：命名管道协议（请求：查询词+max；应答：路径[]+状态+indexReady）。ACL 限当前用户 SID。主程序侧 `LocalFileIndexSource : IItemSource` 客户端，`IsAvailable` 走 `LocalFileIndexGate.ShouldQuery(Evaluate(facts))`，`SearchAsync` 经管道取结果、用 `LocalFileIdentity` 映射 `Item`。注册进 `SearchService` 实时源 ⇒ 快捷搜索/主窗自动出本地文件。
- **AC-D3 UAC + 首扫 UI**：设置页 `ToggleSwitch` → 开启触发一次 `RunAs` 安装服务；`Indexing` 期显进度条；关→停服务、回落。文案对齐用户要求。
- **AC-D4 状态回流**：服务把 `ServiceInstalled/Running/IndexReady` 经管道/注册表回传主程序，喂给 `LocalFileIndexFacts`。

## 5. 验收清单（真机）
① 默认关：任务管理器无 Everything.exe / 无服务，内存无增长；② 开启→一次 UAC→首扫进度→可全盘搜；③ 未授权取消：不提示扫描、功能保持关；④ 关闭：服务停、Everything 私有实例退出；⑤ 快捷搜索/主窗出本地文件、可置顶/打标/拖出（复用既有 items 链路）。
